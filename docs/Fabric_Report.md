# Fabric Report — PINN Heat Equation Simulation

## Project Overview
This project explores solving the 1D heat equation using a Physics-Informed Neural Network (PINN). Instead of relying on traditional grid-based finite difference methods, this approach uses deep learning to learn a continuous surrogate function that obeys the underlying physical laws.

## PINN Pipeline Summary
The implementation follows a mesh-free approach to approximate the PDE solution:
- **Data Generation**: A mesh-free dataset was generated by randomly sampling collocation points in the spatiotemporal domain, alongside initial condition and boundary condition points.
- **Model Architecture**: A Flax Linen Multilayer Perceptron (MLP) named `HeatSurrogate` was constructed to approximate the temperature field.
- **Physics Loss**: The fundamental heat equation residual ($u_t - \alpha u_{xx}$) was enforced using JAX automatic differentiation to compute the exact gradients of the network.
- **Training**: The model was optimized using the Optax Adam optimizer over 5000 epochs, effectively minimizing the combined boundary and physics losses.
- **Visualization**: We created static and interactive 3D visualizations to examine the learned temperature field across the spatial and temporal domains.

## Fourier Neural Operator (FNO) vs PINN

- While a PINN learns a specific mapping from coordinates $(x,t)$ to a solution $u(x,t)$ for one fixed initial condition, an FNO learns an operator that maps entire input function spaces (like any initial temperature profile) to entire output solution spaces.
- FNOs perform convolutions in the frequency domain, allowing them to efficiently capture global spatial patterns and resolve physical phenomena independent of the specific grid resolution.
- Because an FNO learns the generalized mapping of the underlying physics operator rather than a single solution instance, it achieves "zero-shot" predictions, seamlessly solving for entirely new initial conditions without retraining from scratch.
